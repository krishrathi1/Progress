## Origin

Java began in **1991** at **Sun Microsystems** as project **"Green"**, led by **James Gosling** (the "father of Java"), along with Mike Sheridan and Patrick Naughton. The goal was a language for **consumer electronics** (set-top boxes, smart appliances), so it had to be **portable and small**.

- The language was first named **Oak** (after an oak tree outside Gosling's office).
- "Oak" was already trademarked, so it was renamed **Java** (after Java coffee) in **1995**.
- **1995**: Public release of **Java 1.0** with the slogan **"Write Once, Run Anywhere"**.
- **2010**: **Oracle** acquired Sun Microsystems and now stewards Java.

## Why It Succeeded

Its rise coincided with the **web boom**. Applets let Java run interactive content inside browsers, and platform independence made it ideal for a heterogeneous internet.

## Version Timeline

| Version | Year | Landmark Features |
|---------|------|-------------------|
| JDK 1.0 | 1996 | First stable release |
| J2SE 5.0 | 2004 | Generics, enums, autoboxing, annotations |
| Java SE 8 | 2014 | **Lambdas, Streams**, functional interfaces |
| Java SE 9 | 2017 | Module system (JPMS), 6-month release cadence |
| Java SE 11 | 2018 | First **LTS** under new cadence |
| Java SE 17 | 2021 | LTS; sealed classes, records |
| Java SE 21 | 2023 | LTS; virtual threads, pattern matching |

## Naming Evolution

```text
1991: "Green" project
      -> language "Oak"
1995: renamed "Java" + public launch
2010: Oracle acquires Sun
```

## Key points

- Created by **James Gosling** at **Sun Microsystems**, started 1991.
- Originally called **Oak**, renamed **Java** and released in **1995**.
- Designed first for **consumer electronics**, then thrived on the **web**.
- **Oracle** acquired Sun in **2010**.
- **Java 8 (2014)** was a turning point with lambdas and streams; **LTS** versions (8, 11, 17, 21) are used long-term in production.
